# Software Architecture & Real-Time Task Dispatching

This document outlines the software design patterns, digital signal processing algorithms, and finite state machine logic governing the **AgriFlow-EdgeAI** firmware.

---

## 1. Architectural Philosophy

Standard hobbyist firmware implementations rely on sequential, blocking `delay()` calls inside the `loop()` function. This creates severe embedded vulnerabilities:
- During a `delay(5000)` call, the microcontroller cannot service incoming Wi-Fi/Blynk packets, trigger safety watchdogs, or detect an abrupt drop in reservoir water level.
- Any network disconnection stalls execution indefinitely.

AgriFlow-EdgeAI employs a **Cooperative Multi-Tasking Event Loop** governed by 64-bit microsecond timestamps (`millis()`). Every subsystem executes as an asynchronous manager object with its own polling cadence, achieving near-zero latency concurrency without the memory overhead of multi-threaded FreeRTOS task stacks.

## 3. Digital Signal Conditioning: Moving Average Filter

Due to the high input impedance of the ESP32 ADC and electromagnetic emissions generated by the switching pump motor and relay contacts, raw analog reads exhibit transient voltage spikes.

To eliminate these transients, `SensorManager` implements a **10-sample circular sliding-window Moving Average Filter (MAF)** on both `GPIO35` (Soil) and `GPIO34` (Reservoir Level):

$$y[n] = \frac{1}{N} \sum_{k=0}^{N-1} x[n - k], \quad \text{where } N = 10$$

### Signal-to-Noise Ratio (SNR) Improvement
By averaging $N=10$ statistically independent, Gaussian-distributed noise samples, the theoretical Signal-to-Noise Ratio improvement is:

$$\Delta\text{SNR} = 10 \log_{10}(N) = 10 \log_{10}(10) = 10.0\text{ dB}$$

This eliminates false dry-soil trips caused by momentary relay switching noise or pump current surges.

## 4. Hysteresis Decision Control Model

Single-threshold irrigation controllers suffer from **contact chatter**—as soon as soil moisture hovers around the cutoff threshold, minor fluctuations cause the relay to toggle on and off every few seconds, rapidly destroying the relay contacts.

AgriFlow-EdgeAI resolves this via a **Dual-Threshold Hysteresis Deadband**:

```text
    100% ┌───────────────────────────────────────────────┐
         │                                               │
         │   Target Saturation Region                    │
     65% ├───────────────────────────────────────────────┤ <── SOIL_WET_THRESHOLD
         │                                               │     (Pump Disengages)
         │   HYSTERESIS DEADBAND (State Maintained)      │
         │   (Zero relay switching in this zone)         │
     35% ├───────────────────────────────────────────────┤ <── SOIL_DRY_THRESHOLD
         │                                               │     (Pump Engages)
         │   Moisture Deficit Region                     │
      0% └───────────────────────────────────────────────┘
```

- **Deficit Trigger**: When moisture drops strictly below **35%**, the pump engages.
- **Hydration Target**: The pump remains active until soil moisture reaches or exceeds **65%**.
- **Deadband Zone (35% to 65%)**: If soil moisture rises from 35% to 50%, the pump continues running. If moisture dries from 70% to 55%, the pump remains OFF. Relay contact flapping is mathematically eliminated.

## 5. Safety Interlocks & Watchdog Architecture

1. **Hardware Anti-Cavitation Guard**:
   - Evaluated on every cycle. If reservoir water capacity $< 20.0\%$, the pump is hard-locked in the `OFF` state regardless of how dry the soil is or whether a remote manual override command is active.
2. **Maximum Continuous Runtime Timeout (`300 seconds`)**:
   - If a water pipe ruptures, the drip emitter slips out of the pot, or the sensor is displaced from the soil, moisture may never reach 65%. The runtime watchdog forces the relay open after 5 minutes of continuous pumping, logging an emergency alert.
3. **Thermal Rest Cooldown (`30 seconds`)**:
   - Following any pumping cycle, a mandatory 30-second resting window is enforced before the pump can be re-engaged. This dissipates inductive heat in the DC motor windings.
